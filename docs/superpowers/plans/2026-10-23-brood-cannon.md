# Brood Cannon Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (user's choice: native, 2026-10-23 21:34) to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The second 3x3 turret: the Brood Cannon, a huge (FORTRESS) weapon module that lobs an armoured capsule on a high arc onto valid ground targets; the capsule opens like a flower and releases 3 robot spiders that hunt the turret's valid targets, bite, and blow up when they die. Spiders pile up to a per-turret cap, are hunted by hostile mobs, outlive their turret and are never saved.

**Architecture:** `BroodCannonWeapon extends MortarWeapon` (ground-only, min range, arc solver and arc sight, Overwatch arc) with Railgun-style item + FE per shot and a `ready()` gate on the unit cap. A `BroodCapsuleEntity` flies the Mortar's ballistic path, lands, opens after `open_ticks` and spawns the spiders. A small shared unit layer (`TurretUnit` interface, `TurretUnits` registry, aggro goal, turret-fire guard) is written so the Hive Carrier's drones reuse it. `BroodSpiderEntity` is a `PathfinderMob` with vanilla ground navigation and four custom goals.

**Tech Stack:** Forge 1.20.1 (47.4.26), Java 17, GeckoLib 4.8.4, GameTest; Python generators in `tools/`.

**Spec:** `docs/PLAN.md` §8 "Turret 3x3: Javelin Missile, Brood Cannon, Hive Carrier" (shared rules "Aturan bersama", "Brood Cannon", "Detail builder", "Test"). Patterns: the Javelin plan `docs/superpowers/plans/2026-10-23-javelin-missile.md` and its workspace map `.superpowers/sdd/2026-10-23-javelin-missile/big-weapon-map.md` (file:line for every big-weapon concern). Workspace: `.superpowers/sdd/2026-10-23-brood-cannon/`.

## Review Focus
1. **A spider never bites the wrong thing**: a cow or villager beside a husk, another spider, the owner when the filter has no Players, a turret. Tests `spidersBiteOnlyValidTargets`, `spidersLeaveUnitsAndTurretsAlone` (Task 1).
2. **Counting**: the cap holds with capsules in flight; dead spiders free their place; a reload starts at 0. Tests `broodWaitsAtTheUnitCap`, `deadSpidersFreeTheirPlace` (Task 2), `spidersAreNeverSaved` (Task 1).
3. **The turret dies or the chunk unloads**: spiders keep fighting without a home; an unloaded spider or capsule is gone, no orphan in the registry. Tests `spidersFightOnWithoutTheirTurret`, `spidersAreNeverSaved` (Task 1), `capsuleIsNeverSaved` (Task 2).
4. **Friendly death blast**: a dying spider spares non-targets next to it. Test `spiderDeathBlastSparesNonTargets` (Task 1).
5. **A capsule that lands somewhere odd** (on a mob's head, in water, on a slab): it still comes to rest and opens. Test `capsuleOpensWhereItLands` (Task 2: lands on a husk and on water).
