# Hive Carrier Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (user's choice: native, 2026-10-23 21:34) to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The third 3x3 turret: the Hive Carrier, a huge (FORTRESS) weapon module that sends out waves of 3 combat drones while valid targets are in reach. Drones shoot valid targets (flyers too) from range, patrol round the carrier, dive kamikaze when out of bullets or badly hurt, fly home to dock and reload when nothing is left, outlive the carrier, are hunted by hostile mobs and are never saved.

**Architecture:** `HiveCarrierWeapon` (no aiming: `turn_speed` 0, so Overwatch only watches; `fire_interval` 600 = a wave every 30 s while engaged; `ammo_per_shot` 0, so the base never takes an item and `onFire` pays per drone itself: a docked drone costs only its reload FE, a new one a Hive Drone item + `energy_per_drone` FE). `HiveDroneEntity` is a `PathfinderMob` that ignores navigation and gravity: a small state machine sets a desired point each tick and steers toward it (launch → patrol → engage → return → dock, kamikaze from any combat state). It reuses the Brood Cannon's unit layer (`TurretUnit`, `TurretUnits`, the aggro goal, the turret-fire guard) and `MortarWeapon.grounded` is not used: drones shoot flyers.

**Tech Stack:** Forge 1.20.1 (47.4.26), Java 17, GeckoLib 4.8.4, GameTest; Python generators in `tools/`.

**Spec:** `docs/PLAN.md` §8 "Turret 3x3: Javelin Missile, Brood Cannon, Hive Carrier" (shared rules, "Hive Carrier", "Detail builder", "Test"). Patterns: the Brood Cannon plan `docs/superpowers/plans/2026-10-23-brood-cannon.md` and its ledger; the big-weapon map `.superpowers/sdd/2026-10-23-javelin-missile/big-weapon-map.md`. Flight: `setNoGravity(true)`, no navigation; each server tick pick a desired point by state — LAUNCH: straight up 4 blocks from the spawn point, then PATROL; PATROL: a point on a circle of `patrolRadius` / 2 round home at home y + 8, advancing with time; ENGAGE: a point `shotRange` × 0.6 from the target, 4 blocks over it; RETURN: over home, then down onto home + 1.2 (docking within 0.6); KAMIKAZE: the target's centre — and steer: velocity = lerp(velocity, dir × speed, 0.2), the next point stepped up 1 when solid.
