# Bastion Turrets

Futuristic modular turrets for Minecraft Forge 1.20.1 (mod id `bastion`). Design and roadmap: [docs/PLAN.md](docs/PLAN.md).

Status: public beta `0.1.0-beta.3` (version in `gradle.properties`). Nine weapons on two bases, tiers, HP, modules,
targeting GUI, ammo automation and five FE workstations for survival crafting. Not done yet: final sounds,
Jade/JEI/Ponder/Iris compat, profiling. Player-facing description: [docs/release/DESCRIPTION.md](docs/release/DESCRIPTION.md);
upload fields, changelog and image prompts: [docs/release/UPLOAD.md](docs/release/UPLOAD.md).
Manual test checklist: [docs/TESTING.md](docs/TESTING.md).

## Build & run

Requires Java 17.

```sh
./gradlew build        # jar in build/libs/
./gradlew runClient
./gradlew runServer    # dedicated server; accept run/eula.txt first
./gradlew runGameTestServer   # automated checks in dev.bastion.gametest, exits non-zero on failure
./gradlew devClasses runClient -Pshowcase   # scripted scene -> run/screenshots/showcase_*.png, then quits
```

Dev-only test tools (never in the jar):
- `/bastiondev zombie [health] [count]`: spawns sunlight-proof zombies where you look (default 500 HP), from `src/dev`.
- ToroHealth Damage Indicators: floating damage numbers and a target health bar, `runClient` only (it crashes server runs).
- Creative Ammo (`bastion:creative_ammo`, creative tab only, no recipe) is a real item: fits every turret, never runs out.

The showcase (`src/dev`, never in the jar) opens the world `run/saves/showcase` (copy any world there first),
builds a sky platform with three turrets and screenshots the VFX, aim, GUI tabs, damage, tier-up and destruction.

Dependencies: Forge 47.2+ and GeckoLib 4.8+. Create is on the dev runtime classpath only, to test
belt/funnel/chute automation; it is never a dependency of the mod.

## Asset generators

Procedural textures and placeholder sounds are generated, not hand-drawn:

```sh
pip install numpy pillow soundfile
python3 tools/gen_textures.py   # -> assets/bastion/textures/
python3 tools/gen_sounds.py     # -> assets/bastion/sounds/
python3 tools/gen_structures.py # -> data/bastion/structures/ (GameTest arenas)
```

## Models

Gunmetal hard-surface with one cyan glow on every model (`EmissiveLayer.MODEL_GLOW`); each weapon's own colour
only shows in its VFX. Geometry is generated by `tools/blockout/` (`python3 tools/blockout/design_weapons.py`,
`design_base.py`), then `tools/gen_textures.py` paints it and `tools/fit_item_display.py` fits the item transforms.
Blockbench sources live in `blockbench/*.bbmodel` (Bedrock Entity format, read directly by GeckoLib).
After editing, export the geometry to `assets/bastion/geo/<name>.geo.json`, the animations to
`assets/bastion/animations/<name>.animation.json`, then re-run `tools/gen_textures.py`: it paints the
model texture and its emissive `_e` texture from the exported UVs (materials per bone in `MODEL_MATERIALS`).
